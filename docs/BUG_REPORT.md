# NexusSphere 버그 리포트 (Bug Report)

이 문서는 게임 내에서 발견된 버그와 기술적 결함들을 추적하고 관리하기 위한 공식 리포트입니다. 해결된 버그는 체크박스를 통해 표시하며, 진행 상황을 한눈에 파악할 수 있도록 관리합니다.

---

## 🔴 치명적/심각한 버그 (Critical & High)

- [ ] **곡 재시작 시 노트 증발 현상**: 곡을 시작하거나 재시작할 때 간헐적으로 노트가 화면에 나타나지 않는 현상 (`src/games/rhythm/RhythmGame.ts`)
- [ ] **노트 순간이동 (Sync Issue)**: 특정 MIDI 파일 플레이 시 오디오 시작 지점과 비주얼 싱크가 맞지 않아 초기 노트가 중간부터 튀어나오는 현상 (`src/games/rhythm/RhythmGame.ts`)
- [ ] **에디터 테스트 모드 게임오버**: 에디터 내 테스트 플레이 중 노트를 놓치면 게임오버가 발생하여 에디팅 흐름이 끊기는 현상 (`src/games/editor/EditorGame.ts`)

---

## 🟡 기능적 결함 (Medium)

- [ ] **오디오 볼륨 상태 복구 실패**: 음소거(Mute) 후 해제 시, 이전 볼륨 설정값으로 복구되지 않고 초기화되거나 0으로 유지되는 문제 (`src/core/audio/CoreAudioEngine.ts`)
- [ ] **트랙 믹서 상태 불일치**: UI의 Mute 버튼 상태와 실제 오세오 엔진의 Mute 상태가 동기화되지 않는 현상 (`src/ui/TrackMixer.ts`)
- [ ] **곡 정보 0초 표시**: 'My Songs' 등 일부 곡에서 곡 길이다 0초로 표시되는 메타데이터 로딩 문제 (`src/games/rhythm/state/MenuManager.ts`)
- [ ] **에디터 복귀 경로 오류**: 에디터 테스트 모드 종료(Pause/Clear) 시, 에디터 화면이 아닌 곡 선택 화면으로 튕기는 현상 (`src/ui/UIManager.ts`)

---


## 🔵 UI/UX 및 기타 (Low)

- [ ] **트랙 선택기 취소 예외**: `TrackSelector`에서 취소 버튼 클릭 시 적절한 후속 처리가 되지 않아 화면이 멈추거나 예외가 발생하는 현상 (`src/ui/TrackSelector.ts`)
- [ ] **버전 정보 오표시**: 메인 메뉴 등 일부 UI에서 버전 정보가 최신 상태로 반영되지 않는 문제
- [ ] **디버그 로그 과다**: 개발용 디버그 로그가 콘솔에 너무 많이 출력되어 성능 및 가독성에 영향을 주는 상태 (`src/core/audio/AudioEngineLogger.ts`)

---

*현재 해결된 버그가 없습니다. 버그를 수정한 후 이 섹션으로 이동시켜 주세요.*

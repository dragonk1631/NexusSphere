# NexusSphere TODO & Release Plan

이 문서는 출시 전까지 구현해야 할 기능, 보완할 점, 그리고 수정해야 할 기술적 부채들을 추적하고 관리하기 위한 투두 리스트입니다.

## 🚀 새로운 기능 추가 (New Features)

- [x] **로컬 MIDI 파일 지원**: 유저가 보유한 로컬 미디 파일을 불러와서 게임 및 에디터에서 플레이/편집 지원
- [ ] **오디오 파일(MP3 등) MIDI 변환**: 로컬 음악 파일을 MIDI로 변환 및 저장하여 게임 플레이가 가능하도록 지원
- [ ] **오디오 기반 플레이**: 음악 파일과 변환된 MIDI 파일이 함께 있을 경우, 음악 원음을 재생하면서 게임을 플레이하도록 지원
- [ ] **비디오(MV) 기반 플레이**: 동영상/뮤직비디오 파일을 MIDI로 변환하고, 배경에 해당 영상을 재생하면서 게임을 플레이하도록 지원
- [ ] **다양한 게임 모드 추가**: 30초 모드, 60초 모드, 논스톱 모드, 랜덤 모드 등 풍성한 게임 모드 구현
- [ ] **캐릭터 리액션 시스템**: 게임 화면에 캐릭터를 배치하고 노트 판정(Hit/Miss)에 따라 실시간 리액션 구현
- [x] **테마별 메인 메뉴 BGM**: 각 테마의 분위기에 어울리는 메인 메뉴 테마곡 자동 전환 기능
- [x] **V3 관계형 DB 아키텍처 전환**: 정규화된 DB 구조(D1) 및 자동 마이그레이션 시스템 구축
- [x] **전역 API CORS 통신 최적화**: 로컬/운영 환경 간의 완벽한 상호운용성 확보 (OPTIONS 핸들러 도입)

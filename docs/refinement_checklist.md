# NexusSphere Refinement Checklist

이 문서는 게임의 각 컴포넌트별 리파인먼트 작업을 체계적으로 추적하기 위한 체크리스트입니다.
각 단계는 독립적으로 구현, 테스트 및 사용자 확인을 거친 후 다음 단계로 진행합니다.

## 📋 Refinement Tasks

### 🏠 Main Menu

- [ ] **반응형 레이아웃**: 버튼 간격/크기 조정 및 가로 모드 해상도/비율 대응 최적화
- [ ] **테마 색상**: 배경 테마와 어우러지도록 메인 메뉴 버튼 및 UI 색상 톤 조정

### 🛠️ Editor

- [ ] **테스트 중 게임오버 비활성화**
- [ ] **일시정지/클리어 시 "곡 선택" 대신 "에디터"로 복귀**
- [ ] **화면 왼쪽 빈 공간에 "TEST MODE" 표시 추가**
- [ ] **모바일 대응**: 터치 친화적인 +/- 줌 버튼으로 교체

### 🎵 Song Selection

- [ ] **곡 정보 레이아웃**: 4개의 난이도 숫자를 4열 테이블로 정렬 배치
- [ ] **즐겨찾기 저장**: 재시작 후에도 상태 유지 (로컬 저장소 연동)
- [ ] **옵션 저장**: 난이도, 속도, 키 설정(4K/6K) 영구 유지

### 🎮 Gameplay

- [ ] **재시작 버그 수정**: 곡 시작/재시작 시 노트 사라짐 현상 해결
- [ ] **판정선 비주얼**: 리셉터 및 판정선에 비트 싱크 발광(Pulsing) 효과 추가
- [ ] **패널 디자인**: 판정 노트를 버튼 형태로, 주변 레인 하단을 조작 패널 느낌으로 디자인 고도화
- [ ] **콤보 피드백**: 특정 콤보 달성 시 리액션 멘트 및 비주얼 이펙트 추가
- [ ] **결과 화면**: 랭크에 따른 차등 리액션(폭죽 파티클 등) 구현

### ⚙️ Options

- [ ] **가이드 규격 적용**: 마스터 스타일 가이드(v21)의 1px 외곽선 고딕 타이포그래피 및 폰트(Black Han Sans) 적용
- [ ] **스펙트럼 요소**: 토글 버튼, 슬라이더 바 등에 3단계 스펙트럼 그라데이션 및 네온 글로우 효과 반영
- [ ] **글래시 패널**: 옵션 설정창 배경에 리퀴드 광택 및 반투명 유리(Glassmorphism) 효과 고도화

### 🌌 Background & Theme

- [ ] **스펙트럼 파티클**: 배경 파티클 색상을 테크니카 4대 핵심 컬러(Pink, Yellow, Green, Blue)와 동기화
- [ ] **대기 질감**: 배경 그라데이션을 스타일 가이드의 Standard Atmosphere(135deg Lilac-Pink)로 통일
- [ ] **글로우 레이어**: 주요 UI 패널 이면에 대기광(Atmospheric Glow) 효과를 추가하여 공간감 부여

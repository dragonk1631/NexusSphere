# NexusSphere 고강도 성능 최적화 종합 보고서 (Final)

본 문서는 프로젝트의 초기 성능 병목(40FPS 고착)을 해결하고, 모바일 환경에서 안정적인 60FPS(현재 50FPS+ 확보)를 달성하기 위해 수행된 5단계의 정밀 최적화 과정을 기술합니다.

---

## 🚀 1~2단계: 기초 체력 강화 및 자원 누수 차단

- **DPR 상한 조정 (1.5 → 1.25)**: 초고해상도 기기에서의 픽셀 연산량을 약 30% 절감하여 GPU 및 발열 병목을 직접적으로 해결했습니다.
- **블렌딩 모드 최적화**: 모바일에서 부하가 큰 `lighter`, `screen` 대신 연산이 가벼운 `source-over`를 사용하여 드로우 콜 효율을 극대화했습니다.
- **애니메이션 루프 누수 차단**: 게임 진입 후에도 잔존하던 타이틀 화면의 rAF 루프를 인스턴스 파기(`destroy`)를 통해 확실히 제거했습니다.
- **비동기 타이머 제거**: `setInterval` 등 메인 루프와 타이밍을 경쟁하던 레거시 타이머를 제거하여 지터(Jitter)를 억제했습니다.

## 🔗 3단계: 마스터 루프 통합 (Master Loop Orchestration)

- **Worker 루프 제어권 이전**: 백그라운드 워커가 독자적으로 그리던 방식을 폐기하고, 메인 루프의 신호에 맞춰서만 1프레임을 그리도록 단일화했습니다.
- **rAF 체계 단일화**: `main.ts`가 배경 워커, UI, 게임 오브젝트의 렌더링 순서를 완벽히 통제하여 CPU/GPU 자원 점유 합의를 도모했습니다.

## 🕒 4단계: Vsync 정밀화 및 가변 해상도 도입

- **Precision Vsync**: 렌더링 직전의 초정밀 타임스탬프(`performance.now`)를 워커로 전달하여 타이밍 드리프트를 최소화했습니다.
- **Dynamic Resolution Scale**: 워커의 프레임 소요 시간을 실시간 감지하여, GPU 과부하 시 배경 해상도를 0.65x~1.0x 사이에서 동적으로 조절하는 로직을 구현했습니다.
- **통신 오버헤드 최적화**: 워커 메시지 페이로드를 객체에서 배열(`[0, timestamp]`)로 변경하여 메시지 직렬화 비용을 O(1) 수준으로 낮췄습니다.

## ⚡ 5단계: 명령 다이어트 및 Zero Quality Loss 최적화

- **Matrix Glyph Caching**: 매 프레임 1,700회 이상의 `fillText` 호출을 하나로 통합된 **글리프 스프라이트 시트**로 대치하여 명령 부하를 10배 이상 줄였습니다.
- **Path Merging (Hexagons)**: 수백 개의 육각형 드로우 콜을 단 1회의 **경로 병합(Batching)**으로 처리하여 GPU 명령 큐 병목을 완벽히 해결했습니다.
- **Color Pre-computing**: 핫 루프 내에서 매 프레임 수천 번 수행되던 문자열 파싱(`applyAlpha`)을 제거하고, 테마 변경 시점에 색상값을 미리 계산하여 CPU 점유율을 대폭 절감했습니다.
- **캐시 생명주기 관리**: 가변 해상도 조절 시 정적 텍스처(Sprites)는 파기하지 않고 유지하도록 설계하여 렌더링 성능 스파이크를 방지했습니다.

## 📝 향후 과제 (Roadmap to Solid 60FPS)

현재 50FPS 이상의 안정적인 성능을 확보했으나, 완전 고정 60FPS를 위해 다음과 같은 추가 검토가 가능합니다.

1. **단일 캔버스 아키텍처**: 투명 레이어 합성을 없애기 위해 배경 워커를 게임 캔버스의 하부 로직으로 완전 통합 고려.
2. **WebAssembly (WAsm) 도입**: 파티클 물리 연산 등 CPU 집중적인 로직을 WAsm으로 이관하여 연산 속도 극한 최적화.

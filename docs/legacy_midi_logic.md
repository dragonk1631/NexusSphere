# [Golden Standard] Legacy MIDI Charting Logic (v1d75924)

이 문서는 사용자님이 "가장 완벽한 일반 MIDI 채보 품질"로 검증하신 **`1d75924`** 커밋 시점의 핵심 로직을 보존하기 위해 작성되었습니다. 향후 모든 일반 MIDI 로직의 수정 시 이 문서를 절대적 기준으로 삼습니다.

## 核心 배치 규칙 (Lane Allocation)

### 1. 엄격한 양손 배분 (Hand Alternation)

- **스트림/버스트**: 리듬감을 위해 무조건 양손을 번갈아 가며 배치합니다 (`useLeftHand = (lastHand !== 'left')`).
- **피로도 관리 (Fatigue)**: 단일 노트의 경우 한 손으로 연속해서 3개(`FATIGUE_THRESHOLD = 3`) 이상 치지 않도록 강제 스왑합니다.

### 2. 난이도별 동시치기 제한 (Chord Limits)

- **NORMAL / EASY**: 동시치기 **최대 1개 (단선율)**로 엄격히 제한합니다.
- **HARD**: 동시치기 **최대 2개**까지 허용합니다.

### 3. 롱노트 인체공학적 공백 (Hold Buffers)

- 모든 롱노트 뒤에는 **정확히 60틱(약 1/16박자)**의 "심리적/물리적 공백"을 둡니다.
- 이 공백은 롱노트 직후에 바로 노트가 나와서 손가락이 꼬이는 현상을 방지하는 핵심 규칙입니다.

### 4. 물리적 겹침 방지 (Safety Drop)

- 모든 라인이 롱노트로 점유되어 있어 배치가 불가능할 경우, 억지로 겹치게 만드는 대신 **지능적으로 노트를 삭제**하여 플레이 가능한 상태를 유지합니다.

## 軌道 수집 및 필터링 (Note Collection)

### 1. 마디별 채널 타겟팅 (Measure-based Channel Targeting)

- `MelodyAnalyzer`가 분석한 마디별 메인 채널(`measureMap`)을 기반으로 노트를 수집합니다.
- 특정 마디에 설정된 채널이 없을 경우, **역방향 탐색(Backward Search)**을 통해 이전 마디의 설정을 계승합니다.

### 2. 채널 독립적 퀀타이즈 (Channel Independence)

- 일반 MIDI의 경우 채널 간의 독립성을 보존하기 위해 `${n.channel}_${n.quantizedStartTick}` 형식의 키를 사용하여 필터링합니다. (AI의 GLOBAL 방식과 대조됨)

## 롱노트 판정 기준 (Hold Threshold)

- **기준점**: `beatDurationMs * 0.75` (약 3/4박자) 이상의 길이를 가진 노트만 롱노트로 판정합니다.
- 너무 짧은 노트가 롱노트로 변해 흐름을 끊는 것을 방지합니다.

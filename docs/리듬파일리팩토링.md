# NexusSphere: RhythmGame 구조 혁신 로드맵 v3 (Final)

***

## 🔑 설계 원칙 (모든 단계에 적용)

리팩토링 전 전 단계에 걸쳐 지켜야 할 4가지 불변 원칙입니다.

1. **각 단계는 완료 즉시 배포 가능한 상태를 유지한다** — 중간 단계에서 게임이 깨지면 안 됨
2. **상태(State)는 로직과 함께 이동한다** — 메서드만 옮기고 필드는 남기는 반쪽 분리 금지
3. **모듈 간 통신은 반드시 인터페이스를 통한다** — 구체 클래스를 직접 참조하면 분리가 무의미
4. **각 단계 시작 전 체크리스트를 반드시 완성한다**:

```text
□ 이동할 메서드 목록
□ 함께 이동할 상태(필드) 목록
□ 외부에 노출할 인터페이스 정의
□ 이 단계 완료 후 RhythmGame.ts 예상 잔존 줄 수
□ 롤백 조건 (이 버그가 발생하면 이 단계를 되돌린다)
```

## 🏗️ 단계 0: 사전 준비 — 의존성 지도 확정

리팩토링 전에 **순환 참조 위험 구조**를 반드시 확인합니다.

```text
현재 의존성 (문제 없음):
RhythmGame → NoteFactory (VisualNote import)
RhythmGame → ScoreManager
RhythmGame → RenderCache
RhythmGame → ThemeManager
RhythmGame → GameTransition

생성 예정 파일들의 의존성 규칙:
types/        → 외부 의존 없음 (리프 노드)
constants/    → types/ 만 참조 가능
systems/      → types/, constants/ 만 참조 가능
state/        → types/, constants/, systems/ 참조 가능
renderer/     → types/, constants/, systems/, state/ 참조 가능
RhythmGame    → 모든 것을 참조 가능 (오케스트레이터)

⛔ 절대 금지: types/ → 게임 클래스 참조
⛔ 절대 금지: systems/ → renderer/ 참조 (역방향)
⛔ 절대 금지: state/ → renderer/ 참조 (역방향)
```

### `RhythmGame.update()` 최종 형태

public update(delta: number): void {
    this.cachedNow = performance.now();
    this.transitionSystem.update(delta);
    if (this.currentState === GameState.PLAYING) {
        const t = this.audioEngine.getPreciseTime() * 1000;
        this.gameplayManager.update(delta, t);
        this.judgmentSystem.updateMissedNotes(t);
        this.particleSystem.update(delta);
    }
    if (this.currentState === GameState.MENU) {
        this.menuManager.updateAnimation(delta);
    }
}

### `RhythmGame.render()` 최종 형태

```typescript
public render(): void {
    const ctx = this.ctx;
    const w = this.canvas.width, h = this.canvas.height;
    switch (this.currentState) {
        case GameState.MENU:    this.menuRenderer.render(ctx, w, h); break;
        case GameState.PLAYING: this.gameplayRenderer.render(ctx, this.visualNotes); break;
        case GameState.RESULT:
        case GameState.GAMEOVER: this.resultRenderer.render(ctx, w, h, this.currentState); break;
    }
    this.effectsRenderer.renderEffects(ctx);
    this.effectsRenderer.renderTransition(ctx); // 항상 최상단
}
```

# 개발 일지: 성능 최적화와 디자인 원상복구의 여정 (2026-03-15)

## 🌟 개요

오늘은 'NexusSphere'의 사용자 경험을 한 단계 끌어올리기 위해 모바일 최적화, 성능 안정화, 그리고 가장 중요한 시각적 정체성인 롱노트 디자인 복구 작업을 진행했습니다.

---

## 🚀 주요 작업 내용


### 1. 모바일 환경 성능 최적화

모바일 기기에서도 PC와 같은 부드러운 60FPS 경험을 제공하기 위해 하드웨어 부하를 지능적으로 관리하도록 개선했습니다.

- **파티클 시스템 최적화**: 모바일 감지 시 최대 파티클 수를 50% 제한하고 생성 로직을 간소화했습니다.
- **효과 렌더러 조정**: 충격파 및 글리치 효과의 복잡도를 낮추어 GPU 병목 현상을 해결했습니다.
- **레인 렌더링 간소화**: 그라데이션 단계를 조정하여 시각적 품질은 유지하되 드로잉 부하를 낮췄습니다.

### 2. 화면 안정성 및 UI 성능 향상

고질적인 화면 깜빡임 현상을 해결하고, 메뉴 화면의 응답성을 획기적으로 개선했습니다.

- **중앙 집중식 캔버스 클리어**: 각 렌더러에 파편화되어 있던 `clearRect` 호출을 `main.ts` 루프 시작 시점으로 통합하여 프레임 간 깜빡임을 완전히 제거했습니다.
- **메뉴 오프스크린 캐싱**: 곡 선택 화면의 정적 요소와 레이아웃 계산을 `OffscreenCanvas`에 캐싱하여, 메뉴 이동 시 발생하던 프레임 드랍을 해결했습니다.

### 3. 롱노트 디자인의 완벽한 복구

성능 개선 과정에서 유실되었던 사용자가 가장 선호하는 롱노트 디자인을 과거 코드(Commit `ab27a84`)에서 찾아 원상복구했습니다.

- **벡터 기반 렌더링 귀환**: 텍스처 슬라이싱 방식 대신 원본의 날카롭고 깔끔한 폴리곤 채우기 방식으로 복구했습니다.
- **시각적 밸런스**: 중앙의 선명한 하얀색 스파인(3.5px)과 심플한 그라데이션 하이라이트를 재적용했습니다.
- **꼬리 노트 높이 조정**: 머리 노트 높이의 정확히 **절반(50%)**으로 조정하여 시각적 안정감을 확보했습니다.

### 4. 배포 및 빌드 안정화

- **빌드 오류 수정**: TypeScript의 엄격한 미사용 변수 체크(`alpha` 파라미터)를 해결하여 `npm run build`가 완벽하게 통과하도록 조치했습니다.
- **브랜치 동기화**: 모든 검증을 마친 코드를 `develop` 및 `main` 브랜치에 성공적으로 푸시하여 배포를 완료했습니다.

# 2026-04-09 Dev Blog: AI 리듬 분석 엔진 대수술 (Demucs -> Spleeter -> Spotify AI)

오늘의 목표는 리듬 게임의 고점에 도달하기 위해 보컬의 결을 그대로 따라가는 **"완벽한 AI 채보 엔진"**을 만드는 것이었습니다. 여러 번의 시행착오 끝에 의미 있는 기술적 진보를 이루었습니다.

## 1. 주요 작업 내용

### 🧬 보컬 분리 엔진의 혁신 (Spleeter 도입)

- **문제**: 최신 Demucs 엔진이 윈도우 환경(torchcodec)과 충돌하여 작동하지 않았고, 그 결과 분석기가 배경 악기 소리까지 보컬로 착약해 노트가 난잡하게 쏟아짐.
- **해결**: 윈도우 안정성이 검증된 **Spleeter 4stems** 모델로 전격 교체.
- **결과**: 드럼, 베이스, 배경음을 물리적으로 분리한 뒤 '순수 보컬'만 분석기에 전달함으로써 instrumental 구간의 '가짜 노트'를 90% 이상 제거.

### 🧠 딥러닝 기반 멜로디 채보 (Spotify Basic-Pitch)

- **변화**: 단순 수학 공식(Librosa pYIN)을 버리고, 수천 시간의 인간 목소리를 학습한 스포티파이의 **Basic-Pitch 신경망**을 도입.
- **성과**: 가수의 미세한 떨림, 호흡, 웅얼거림까지 사람과 유사한 감각으로 음표(MIDI)화 성공. 특히 롱노트(Hold)를 가수의 실제 발음 길이에 맞춰 생성하도록 튜닝함.

### 🛠️ 윈도우 파이썬 환경 최적화

- **Numpy 버전 호환성 해결**: Spleeter와의 호환을 위해 Numpy를 1.26.4로 다운그레이드하여 바이너리 오류 해결.
- **Portable FFmpeg 주입**: 시스템 경로(PATH) 설정 없이도 작동하는 `static-ffmpeg`를 연동하여 'ffmpeg binary not found' 이슈를 원천 차단.

## 2. 작업 결과 (Before & After)

- **노트 밀도 최적화**: 곡당 3,500개(난잡함) -> **700~900개(정돈됨)** 로 최적화.
- **보컬 싱크**: 배경 악기에 반응하던 채보에서 가수의 목소리에만 반응하는 채보로 진화.
- **롱노트 구현**: 한 박자 단위로 잘리던 롱노트가 가수의 실제 호흡 길이에 맞춰 가변적으로 생성됨.

## 3. 남아있는 과제 가이드

- **정확도 고도화 (70% -> 90%+)**: 현재 Spleeter의 분리 성능과 Basic-Pitch의 분석 성능을 더 정밀하게 맞추는 하이퍼파라미터 튜닝이 추가로 필요함.
- **가사 및 UI 연동**: 추출된 보컬 노트를 바탕으로 화면에 가사를 띄우거나 보컬 가이드 비주얼라이저를 추가할 가능성 확보.

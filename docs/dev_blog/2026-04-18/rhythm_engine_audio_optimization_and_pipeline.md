# 개발 블로그: 오디오 엔진 고도화 및 자산 파이프라인 자동화 (2026-04-18)

오늘은 NexusSphere의 사용자 경험 핵심인 오디오 시스템을 대폭 개선하고, 개발자 경험(DX)을 위한 자산 처리 프로세스를 완전히 자동화하는 성과를 거두었습니다.

---

## 🎧 오디오 엔진 및 프리뷰 시스템 혁신

### 1. 전체 MP3 기반 고음질 프리뷰 전환
그동안은 용량 최적화를 위해 10초 내외의 낮은 품질의 샘플 파일을 미리보기로 사용해왔습니다. 하지만 이제 성능상의 병목을 해결하고 **전체 MP3 파일을 직접 스트리밍**하는 방식으로 전환했습니다.
- **스트리밍 기술**: `HTMLAudioElement`를 활용해 필요한 부분만 버퍼링하여 로딩 속도와 메모리 효율을 모두 잡았습니다.
- **하이라이트 재생**: `previewStart` 필드를 도입하여 노래의 가장 듣기 좋은 지점(후렴구 등)부터 프리뷰가 시작되도록 개선했습니다.

### 2. 하이파이 음량 노멀라이즈(Normalization) 도입
곡마다 들쭉날쭉하던 음량 문제를 해결하기 위해 업계 표준인 사전 분석 기반 노멀라이즈 시스템을 구축했습니다.
- **FFmpeg 분석**: 배포 시 모든 음원의 피크 전압을 측정하여 `-1.5dB` 기준의 보정값(`normalizationGain`)을 자동 계산합니다.
- **일관된 경험**: 이제 어떤 곡을 선택하든, 게임을 플레이하든 항상 일정한 음량 밸런스가 유지됩니다.

### 3. 스트리밍 재생 안정화 (끊김 해결)
프리뷰 시작 시 발생하던 미세한 끊김 현상을 정밀 진단하여 해결했습니다.
- **싱크 유예 시간**: 재생 초기 브라우저의 내부 탐색(Seek) 시간을 보장하기 위해 1.5초의 감시 유예 시간을 도입했습니다.
- **임계치 최적화**: 싱크 보정 알고리즘을 부드럽게 조정하여 불필요한 재탐색으로 인한 버벅임을 완전히 제거했습니다.

## 🛠 자산 파이프라인 완전 자동화

신곡 추가 과정이 "파일 복사"와 "명령어 한 줄"로 끝날 수 있도록 모든 프로세스를 자동화했습니다.

### 1. AI 기반 미디 자동 생성
`Demucs`와 `Librosa` 엔진을 결합하여 MP3 음원에서 드럼, 보컬, 베이스 트랙을 분리하고 게임 비트맵용 미디를 자동으로 생성하는 파이프라인을 구축했습니다.

### 2. 통합 배포 프로세스 (`deploy_assets.mjs`)
복잡했던 배포 과정을 하나로 묶었습니다.
- **자동 동기화**: 신규 곡을 자동으로 레지스트리에 등록합니다.
- **자동 분석**: 음량 분석 및 노멀라이즈 적용을 수행합니다.
- **자동 번들링 & 업로드**: 자산을 압축하여 Cloudflare R2 스토리지에 즉시 배포합니다.

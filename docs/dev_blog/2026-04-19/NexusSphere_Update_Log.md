# Dev Blog: 2026-04-19 NexusSphere Update Log

## "글로벌 랭킹 시스템 구축 및 엔진 안정화 대수술"

### 📅 개요

오늘의 주요 목표는 500 에러로 인해 마비되었던 랭킹 시스템을 복구하고, 사용자 실명을 리더보드에 반영하며, 오디오 엔진의 고질적인 프리징 문제를 해결하는 것이었습니다.

---

### 1. 오디오 엔진 안정성 강화 (Audio Engine Stabilization)

- **문제**: 게임 플레이 중 노트가 멈추거나 시간이 흐르지 않는 현상 발생.
- **원인**: `syncTime` 로직이 메뉴 배경음악 재생 여부만 체크하여 정밀 클럭 게이팅이 오작동함.
- **해결**:
  - `CoreAudioEngine.isBGMPlaying()`을 MIDI 및 스트리밍 상태까지 포함하도록 확장.
  - 게임 종료 및 오디오 정지 시 시간 드리프트 로그가 남지 않도록 동기화 로직 최적화.

### 2. 서킷 브레이커(Circuit Breaker) 시스템 도입

- **문제**: 서버가 꺼져 있을 때 발생하는 404/500 에러가 콘솔 로그를 도배하여 개발 및 플레이 방해.
- **해결**: `ScoreManager`와 `RankingUI`에 서버 상태 플래그를 도입, 한 번 통신에 실패하면 일정 기간 불필요한 네트워크 요청을 차단하여 성능과 가독성 확보.

### 3. 글로벌 랭킹 시스템 아키텍처 재구축

- **백엔드 라우팅 최적화**: 단일 파일(`scores.ts`) 구조를 디렉토리 기반(`submit.ts`, `top.ts`, `index.ts`)으로 세분화하여 프론트엔드와 1:1 매칭.
- **포트 충돌 해결**: 프론트엔드(5173)와 백엔드(8788) 포트를 분리하고, Vite 프록시 설정을 통해 원활한 통신 브릿지 구축.
- **보안 강화**: 점수 위변조 방지를 위해 HMAC-SHA256 디지털 서명 검증 로직 구현.

### 4. 자가 치유(Self-Healing) 데이터베이스

- **문제**: 로컬 환경마다 다른 D1 데이터베이스 경로 및 테이블 부재로 인한 500 에러 지속.
- **해결**: 백엔드가 실행될 때 테이블 존재 여부를 스스로 검사하고, 없을 경우 즉석에서 생성하는 자동화 로직을 탑재하여 환경 의존성 제거.

### 5. 사용자 실명 동기화 (Identity Sync)

- **문제**: 로그인된 계정이 있음에도 랭킹에 'Anonymous Player'로 표시됨.
- **해결**:
  - Clerk `AuthService`를 연동하여 실제 사용자 이름을 페이로드에 포함.
  - 백엔드에 **UPSERT** 로직을 적용하여, 플레이할 때마다 기존 익명 기록을 실제 이름으로 소급 업데이트하도록 구현.

### 6. 개발자 경험(DX) 개선

- **`start_all.bat`**: 클릭 한 번으로 백엔드, 프론트엔드, 브라우저 기동까지 모두 처리하는 통합 실행 스크립트 작성.

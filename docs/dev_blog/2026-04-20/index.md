# Dev Blog: 리듬의 근본 복구와 성장의 즐거움 (2026-04-20)

안녕하세요, NexusSphere 팀입니다! 오늘은 엔진의 핵심인 '손맛'을 되살리고, 플레이어의 성취감을 극대화하는 중요한 업데이트를 진행했습니다. 오늘 진행된 주요 작업들을 상세히 정리해 드립니다.

---

## 1. 리듬의 정교함 복구: 32비트 간격 제한 도입
기존의 AI 채보 엔진은 지저분한 노이즈를 걸러내는 과정에서 16비트 강제 제약을 두어 음악의 세밀한 롤(Roll)이나 빠른 베이스 리듬이 생략되는 아쉬움이 있었습니다.

- **변경 사항**: 모든 난이도의 노트 간격 제약을 **32비트(ppq/8, 60 ticks)**로 과감하게 완화했습니다. 
- **효과**: 이제 사용자가 '그 시절' 느꼈던 쫄깃한 연타와 촘촘한 리듬이 음악과 완벽하게 싱크되어 돌아왔습니다. AI 채보에서도 음악적인 디테일이 모두 살아나 훨씬 다이내믹한 플레이가 가능합니다.

## 2. 4키 모드 비활성 레인 UI 전면 개편
4키 모드에서 사용하지 않는 양 끝 레인의 시각적 피로도를 줄이고, 정보의 전달력을 높이기 위해 디자인을 전면적으로 수정했습니다.

- **통합 디자인**: 하이웨이 곳곳에 흩어져 있던 'LOCKED' 문구와 '진입금지' 아이콘을 **판정선(Receptor) 내부**로 모두 통합했습니다.
- **프리미엄 에스테틱**:
  - 네온 레드 컬러의 **대형 hazard X 마크** 적용.
  - 보안의 상징인 **자물쇠(Lock) 아이콘**을 프로시저럴 드로잉으로 추가.
  - 희미하게 비치는 **진입금지 엠블럼**으로 디테일 완성.
- **효과**: 화면 하단 판정선 영역에만 집중하면 되어 가독성이 향상되었으며, 전체적인 화면이 훨씬 넓고 깔끔하게 정돈되었습니다.

## 3. 경험치 시스템 & 결과 화면 2단계 브릿지 도입
플레이어의 성장이 눈에 보이고, 그 과정이 축제가 되도록 레벨링 시스템을 완전히 새롭게 설계했습니다.

- **폭풍 성장 곡선 (Fast Leveling Curve)**:
  - 새로운 공식(`40*L^2 + 40*L`)을 도입해 **첫 곡 클리어 시 즉시 레벨 2**에 도달합니다.
  - 이후 레벨마다 필요한 곡 수가 1곡씩 정직하게 늘어나는 정비례 곡선을 구현하여 초반의 엄청난 성취감을 보장합니다.
- **2단계 결과 화면 (Score -> XP Breakdown)**:
  - 점수 확인 후 클릭 시 화면 전체를 덮는 **대형 글래스모피즘 XP 팝업**이 등장합니다.
  - 기본 경험치, 콤보 보너스, 난이도/등급 보너스 등 **획득 내역 상세 테이블**을 제공하여 보상의 투명성을 높였습니다.
  - 레벨업 시 화면 전체가 황금빛으로 진동하는 강력한 연출을 추가했습니다.

## 4. 안정성 및 디테일 최적화
시스템의 완성도를 높이기 위해 다음과 같은 코드 수준의 정리를 진행했습니다.

- **에셋 안정화**: 누락된 클릭 사운드 에셋 경로를 유효한 에셋으로 교체하여 결과 화면 전환 시 발생하던 크래시를 방지했습니다.
- **린트 오류 해결**: 미사용 변수(`EconomyManager`, `pulse`)를 정리하고, 애니메이션 로직에 통합하여 코드 품질을 높였습니다.

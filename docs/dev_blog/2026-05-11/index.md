# Dev Blog: 상점 UI 프리미엄화 및 게스트 경험 최적화 (2026-05-11)

오늘 작업의 핵심은 **상점(Shop) UI의 시각적 완성도를 극대화**하고, **사용자 상태(로그인/게스트)에 따른 명확한 인터페이스 피드백**을 구축하는 것이었습니다.

## 1. 상점 카드 디자인의 표준화 및 프리미엄화

기존에 탭마다 제각각이었던 디자인을 하나의 통합된 `shop-card` 시스템으로 재설계했습니다.

* **타이틀 스타일링**: 메인 메뉴와의 통일성을 위해 'Black Han Sans' 폰트를 적용하고, 강력한 외곽선(Stroke)과 그림자(Shadow) 효과를 추가하여 가독성과 입체감을 동시에 잡았습니다.
* **레이아웃 대칭성**: 우측 상단의 별표시(Rarity)를 제거하고 이름을 중앙 정렬했습니다. 하단의 가격 표시 또한 캡슐 형태의 디자인으로 중앙에 배치하여 완벽한 상하 대칭을 이뤘습니다.
* **캐릭터 디테일**: 캐릭터들의 이름을 전면 대문자에서 첫 글자만 대문자인 Title Case로 변경하여 훨씬 정갈한 느낌을 주었습니다.

## 2. 캐릭터 상태별 감성 UI 적용

캐릭터가 단순히 '잠겨 있음'을 표시하는 것에 그치지 않고, 사용자와 교감할 수 있는 시각적 요소를 추가했습니다.

* **실망한 표정**: 아직 획득하지 못한 캐릭터들은 상점에서 사용자를 보며 **실망하거나 아쉬워하는 표정(MISS 프레임)**을 짓도록 설정했습니다.
* **활성화 피드백**: 현재 사용 중인 캐릭터는 행복한 표정과 함께 펄스 애니메이션이 적용되어 소유욕과 사용감을 강화했습니다.

## 3. 모바일 레이아웃 극대화 (Fill-to-Grid)

모바일 기기의 작은 화면에서도 아이템이 돋보일 수 있도록 공간 효율을 극한으로 끌어올렸습니다.

* **여백 최소화**: 컨테이너 패딩과 그리드 간격을 줄여 아이템 카드가 화면을 가득 채우도록 했습니다.
* **콘텐츠 확대**: 타이틀 크기를 줄이는 대신, 노트 스킨 이미지를 카드 너비의 98%까지 키우고 캐릭터 스프라이트의 스케일을 확대하여 시각적 만족도를 높였습니다.

## 4. 게스트 경험 및 보안 강화

비로그인 상태에서의 상점 이용 규칙을 명확히 하고 시각적으로 차별화했습니다.

* **풀스크린 고정 배너**: 로그인 안내를 화면 전체를 가로지르는 프리미엄 글래스 바(Glass Bar) 형태로 고정 배치했습니다.
* **상호작용 차단**: 게스트 상태에서는 카드를 클릭할 수 없도록(`pointer-events: none`) 막아 오구매를 방지했습니다.
* **시각적 잠금 상태**: 비로그인 시 모든 카드가 흑백 및 저대비 상태로 전환되어, 로그인 후에만 진정한 상점의 가치를 확인할 수 있음을 직관적으로 전달합니다.

## 5. 관리자 도구 보안 고도화 및 God Mode 복구

개발 편의를 위해 잠시 허용했던 보안 우회 로직을 전면 제거하고, 정식 관리자 계정만 접근 가능하도록 시스템을 강화했습니다.

* **어드민 클레임 검증**: 이제 모든 관리자 기능(God Mode)은 Clerk의 `admin` 역할 클레임을 가진 계정에서만 활성화됩니다.
* **보안 우회 로직 제거**: localhost 환경에서 관리자 기능을 무조건 허용하던 취약점을 제거하여, 실제 운영 환경과 동일한 보안 수준을 확보했습니다.

## 6. 사용자 맞춤형 설정 영구 보존 (Persistence)

로그아웃이나 재접속 시에도 사용자의 취향이 유지되도록 `EconomyManager`의 저장 시스템을 혁신했습니다.

* **계정 기반 저장소**: 유저 ID와 연동된 로컬 저장소(`nexus_economy_v1_{userId}`)를 통해 테마, 노트 스킨, 캐릭터 설정을 계정별로 독립적으로 보존합니다.
* **자동 복원**: 로그인 성공 시 `EconomyManager`가 해당 유저의 최신 설정값을 자동으로 불러와 즉시 게임에 적용합니다.

## 7. 캐릭터 시스템 전면 통합 및 UI 안정화

게임의 모든 화면에서 선택한 캐릭터가 완벽하게 동기화되도록 아키텍처를 재설계했습니다.

* **전수 조사 및 통합**: 상점뿐만 아니라 도감, 전 세계 랭킹, 게임 플레이 하이웨이, 결과 화면까지 모든 지점에서 선택한 캐릭터가 실시간으로 반영됩니다.
* **캐릭터 선택 UX 개선**: 상점의 캐릭터 탭 렌더링 로직을 독립시켜 안정성을 높였으며, 선택 즉시 체크 표시(`✓`)와 애니메이션 피드백이 제공되도록 개선했습니다.

## 향후 계획

이번 업데이트를 통해 상점은 단순한 구매 창을 넘어, 게임의 프리미엄한 가치를 전달하는 핵심 공간으로 거듭났습니다. 또한 보안과 개인화라는 두 마리 토끼를 잡아 서비스의 안정성을 한 단계 끌어올렸습니다. 다음 단계에서는 구매 완료 시의 화려한 연출과 새로운 캐릭터 스프라이트 애니메이션을 추가할 예정입니다.

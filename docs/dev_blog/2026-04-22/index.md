# Dev Blog: 프리미엄 엠블렘 시스템과 콜렉션 UI의 진화 (2026-04-22)

안녕하세요, NexusSphere 팀입니다! 오늘은 플레이어의 등급을 상징하는 **DJ Class 엠블렘 시스템**을 상용 게임 수준으로 끌어올리고, 이를 한눈에 확인하고 수집할 수 있는 **콜렉션 UI**를 대대적으로 개편했습니다. 오늘 적용된 놀라운 시각적 변화들을 소개합니다.

---

## 1. 명예의 상징: 군사 훈장(Military Medal) 시스템 도입

단순한 도형 형태였던 기존 엠블렘을 벗어나, 진정한 명예와 성취를 상징하는 **군사 훈장 스타일**로 모든 디자인을 재구현했습니다.

- **디자인 철학**: 상단의 화려한 **리본 타이(Ribbon tie)**와 하단의 묵직한 **메달 배지(Badge)**가 결합된 정통 훈장 형태를 채택했습니다.
* **역동적인 컬러 파이프라인**: 초보(Beginner) 등급의 실버 브론즈부터, 딥 블루, 에메랄드, 골드, 오렌지, 그리고 최상위 등급의 마스터 퍼플까지 이어지는 화려한 그라데이션을 통해 등급 상승의 재미를 극대화했습니다.

## 2. 프리미엄 날개 프레임(Wing Frame) 통합 디자인

모든 등급의 플레이어가 자부심을 느낄 수 있도록, **'프리미엄의 대중화'**를 목표로 프레임 시스템을 고도화했습니다.

- **통일된 웅장함**: 입문자 등급부터 최상위 등급까지 모두 **고해상도 이중 날개 프레임**을 기본 사양으로 적용했습니다. 
- **티어별 디테일 진화**: 기본 날개 실루엣의 통일성을 유지하면서도, 티어가 올라갈수록 프레임의 겹이 많아지고 상단에 별(Star)이나 왕관(Crown) 장식이 추가되는 등 정교한 밀도 차이를 두었습니다.

## 3. 콜렉션 UI HUD 및 메달 아카이브(Medal Archive) 구현

수집한 훈장들을 한눈에 감상하고 관리할 수 있는 전용 공간을 마련했습니다.

- **HUD 레이아웃 재배치**: 화면 상단 대시보드에서 엠블렘을 레벨 정보보다 좌측에 배치하여 시각적 우선순위를 높였습니다.
- **풀스크린 메달 아카이브**: HUD의 엠블렘을 클릭하면 등장하는 **'MEDAL ARCHIVE'** 모달을 구현했습니다. 이를 통해 총 14단계의 계급 체계를 한눈에 조망할 수 있습니다.
- **모바일 랜드스케이프 최적화**: 모바일 가로 모드에서도 정보가 겹치지 않도록 미디어 쿼리를 이용한 반응형 레이아웃을 완성했습니다.

## 4. 잠금 실루엣과 자물쇠 오버레이를 통한 동기부여 강화

아직 도달하지 못한 등급에 대한 호기심과 수집 욕구를 자극하기 위한 UX 장치를 추가했습니다.

- **미스터리 실루엣**: 잠긴 메달은 단순한 무채색이 아니라, **아주 어두운 실루엣 형태**로 표시됩니다. 이를 통해 다음에 해금될 엠블렘의 거대한 날개나 화려한 장식의 윤곽을 미리 엿볼 수 있어 기대감을 조성합니다.
- **네온 자물쇠 오버레이**: 흑백으로 처리된 아이콘 위에 **강렬한 레드 네온 빛의 자물쇠(Padlock) 아이콘**을 얹어 직관적인 피드백을 제공합니다.

## 5. 멀티 브랜치 배포 및 시스템 안정화

개발 및 운영의 안정성을 위해 모든 변경 사항을 최신화했습니다.

- **브랜치 동기화**: 로컬에서 완성된 고퀄리티 SVG 자산과 UI 로직을 `develop` 브랜치에 커밋 후, `main` 브랜치로 병합하여 즉각적인 배포를 완료했습니다.
- **SVG ID 충돌 방지**: 모달 내에서 다수의 엠블렘이 동시에 렌더링될 때 발생할 수 있는 SVG 그라데이션 ID 충돌 문제를 고유 ID 생성 로직(`makeUniqueSVG`)을 통해 원천적으로 해결했습니다.
